# TargetScan

Консольный инструмент разведки веб-периметра на Go. На вход подаётся один домен — на выходе список поддоменов, живые HTTP-хосты и найденные директории в виде TXT- и HTML-отчёта.

## Возможности

- **Поддомены из пассивных источников** — HackerTarget, URLScan (API-ключи не нужны).
- **DNS-брутфорс** — встроенный словарь на 5000 слов + поддержка собственного словаря.
- **HTTP-пробинг** — каждый поддомен проверяется по `https://` и `http://`: статус, IP, `<title>`, заголовок `Server`.
- **Брутфорс директорий** — встроенный словарь (~9.7k путей), фильтр по статус-кодам, несколько HTTP-методов, задержка между запросами, детект soft-404 (catch-all).
- **Отчёты** — `<домен>.txt` и `<домен>.html` сохраняются в текущую директорию.

## Как это работает

1. **Сбор поддоменов** — параллельно опрашиваются пассивные источники и идёт DNS-брутфорс; результаты объединяются и дедуплицируются.
2. **HTTP-пробинг** — все найденные поддомены проверяются по HTTP и HTTPS, недоступные отсеиваются.
3. **Брут директорий** — по каждому живому хосту перебирается словарь путей; ответы, неотличимые от эталона «не найдено» (soft-404), отбрасываются. При `429/503` хост ставится на паузу (cooldown).
4. **Отчёт** — формируются TXT и HTML файлы с хостами и найденными путями.

### DNS-брутфорс

- Основной транспорт — **DNS-over-HTTPS** (Cloudflare, Google): устойчив к потерям UDP-пакетов и работает в сетях, где закрыт 53-й порт. Если DoH недоступен — **UDP-резолверы** (1.1.1.1, 8.8.8.8, 9.9.9.9, 8.8.4.4, 1.0.0.1) с предварительным health-check.
- На слово отправляется один A-запрос; NXDOMAIN считается окончательным ответом и не перепроверяется; недоступные резолверы автоматически исключаются.
- **Wildcard DNS** определяется и фильтруется по IP.
- Действует **лимит времени** (`-brute-timeout`, по умолчанию 90 секунд) — брут не может затянуть прогон. Его можно отключить флагом `-no-brute`.

## Установка

Требуется Go 1.25+.

```bash
git clone https://github.com/mogpnet/targetscan.git
cd targetscan
go build -o targetscan ./cmd/recon
```

## Использование

```bash
./targetscan -d example.com
```

### Флаги

| Флаг | По умолчанию | Описание |
|---|---|---|
| `-d` | — | Целевой домен (обязателен) |
| `-w` | встроенный (5000 слов) | Свой словарь для DNS-брута |
| `-dw` | встроенный (~9700) | Свой словарь директорий |
| `-t` | `50` | Количество потоков |
| `-v` | `false` | Подробный вывод (DEBUG) |
| `-no-brute` | `false` | Отключить DNS-брут (только пассивные источники) |
| `-brute-timeout` | `90` | Лимит DNS-брута в секундах (`0` — без лимита) |
| `-no-dir` | `false` | Отключить брут директорий |
| `-methods` | `GET` | HTTP-методы для брута директорий (например `GET,POST`) |
| `-status` | `200,301,302,403,405` | Какие статус-коды считать находками |
| `-delay` | `50` | Пауза между запросами к директориям, мс (защита от WAF) |

Примеры:

```bash
# только поддомены и отчёт, без брута директорий
./targetscan -d example.com -no-dir

# только пассивные источники, без DNS-брута
./targetscan -d example.com -no-brute

# свой словарь и 100 потоков
./targetscan -d example.com -w words.txt -t 100

# несколько методов и расширенный набор статусов
./targetscan -d example.com -methods GET,POST -status 200,201,301,302,401,403
```

```

[*] Запуск параллельного сбора из пассивных источников...
  [*] DNS-брутфорс [DoH cloudflare-dns.com, dns.google]: 5000 слов, 150 потоков, лимит 1m30s
  [+] [URLScan] Успешно получено: 100 записей
  [+] DNS-брутфорс завершён: проверено 5000 слов, найдено 1

[+] Всего уникальных поддоменов найдено: 2

[*] Старт HTTP-пробинга (2 хостов, 50 потоков)...
  [+] HTTP-пробинг завершен. Найдено живых веб-сервисов: 2

[+] Список живых хостов:
[200] http://example.com       | IP: 93.184.216.34 | Title: Example Domain
```

HTML-отчёт содержит сводные карточки (поддомены, живые хосты, директории), таблицу хостов и сгруппированные по хостам найденные пути. TXT-отчёт — то же самое в текстовом виде.
